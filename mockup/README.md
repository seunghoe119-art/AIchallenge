# AI Challenge · 발표용 목업

이 폴더에는 Android 중심 스마트 전술 시스템의 **정적 발표 목업**만 있습니다.

## 열어 보기

GitHub Pages가 설정되면 `mockup/` 경로에서 화면을 확인할 수 있습니다. 저장소 기본 페이지 URL은 저장소 소유자가 Pages 설정을 마친 뒤 확인하세요.

## 시연 범위

- 로고 인트로와 10초 음성 입력 화면
- 음성 인식 결과 문장 확인 및 수정 화면
- 5초 취소 가능 자동 전송 흐름
- AI 답변과 문장별 출처 미리보기
- 근거가 없는 답변 및 오프라인 안내 상태

화면 전환과 타이머는 발표를 위한 시뮬레이션입니다. 실제 마이크, 음성 인식, RAG 검색, AI API, 답변 저장 기능은 연결하지 않았습니다. 기존 PDF와 RAG 자료는 이 목업의 실행 코드에서 사용하지 않습니다.
