# 화재 RAG 자료 준비

화재1 205개 + 화재2 85개 = PDF 290개, 613쪽을 대상으로 페이지별 텍스트를 추출했습니다. 원본 PDF는 저장소 최상위의 업로드 경로와 내용을 그대로 유지합니다.

## 파일
- manifest.json: 자료 ID, 과목, 분할 순서, 원본 경로, SHA-256, 페이지 수
- pages.jsonl: 페이지별 텍스트, 자료 ID, 실제 PDF 쪽수, 원본 버전 URL
- verification.json: 추출 통계 및 검토 항목
- prepare_rag.py / requirements.txt: 재생성 도구와 의존성

## 재생성
저장소 루트에서 실행합니다.
```sh
python -m pip install -r rag/requirements.txt
python rag/prepare_rag.py --repo . --output rag
```

## 검증 결과와 한계
화재1 001–205 및 화재2 001–085가 모두 있고, 동일 내용의 중복은 없습니다. 290개 파일의 SHA-256이 로컬 원본과 일치했습니다. 613개 페이지 ID의 유일성과 각 파일의 페이지 순서·출처 연결을 검증했습니다. 대표 화재 전술 및 화재2 페이지의 렌더링을 추출 텍스트와 비교했습니다. 전 페이지 시각 검수는 하지 않았습니다.

텍스트가 거의 없거나 대체문자가 발생한 페이지는 자동 점검에서 발견되지 않았습니다. 이미지가 포함된 82쪽은 그림 의미와 표 구조에 대한 별도 검토가 필요합니다. OCR은 실행하지 않았습니다.

`pdf_page`는 1부터 시작하는 분할 PDF 실제 쪽수입니다. `printed_page_references`는 자료 안의 본문 쪽수 언급을 그대로 수집한 값이며 정확한 페이지 대응표가 아닙니다. 따라서 `printed_page`는 미확정(null)입니다. GitHub 뷰어는 URL의 #page 이동을 지원하지 않을 수 있으므로 앱 뷰어는 pdf_page를 별도로 사용해야 합니다.

시험범위아님 표시가 있는 SOP·SSG도 검색 대상입니다. 시험범위 표시는 검색 제외 또는 순위 하향 조건으로 사용하지 않습니다. 구조·구급은 이번 처리 대상에 포함되지 않습니다.

현재 결과는 RAG용 원본 연결 데이터입니다. 외부 검색 저장소 색인, GPT Astra API 연결, 답변 정확도 검증은 아직 완료되지 않았습니다.
